## Struttura Apache_Iceberg

### Iceberg:
Contiene gli script Python per la gestione delle tabelle Apache Iceberg

### DuckDB:
Contiene gli script Python rgelativi alle query SQL

### openmetadata-docker/Configurazione_OpenMetadata.pdf
File pdf contenente la configurazione di OpenMetadata e le prove pratiche svolte 

### openmetadata-docker/docker-compose-openmetadata.yml
File di configurazione dei container di OpenMetadata e Iceberg-Rest

### openmetadata-docker/postgresql-42.7.5.jar
Driver JDBC PostgreSQL per server REST Apache Iceberg

### Configurazione_Apache_Iceberg.pdf
File pdf contenente le configurazioni di PyIceberg, MinIO, DuckDB, PostgreSQL e le prove pratiche svolte

### docker-compose.yml
File di configurazione dei container di PostgreSQL e MinIO

### pyiceberg.yml
File di configurazione per il collegamento tra PyIceberg, PostgreSQL e MinIO
